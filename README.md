Hotel Management Database System

Overview
A relational database system designed using Microsoft Access and SQL to streamline hotel operations, manage room bookings, track guest details, and organize staff information.

Database Schema & Tables
- GUEST: Stores guest personal details, contact numbers, and identification proof.
- ROOM: Manages room numbers, types, capacities, and nightly rates.
- BOOKING: Handles reservations, check-in/check-out dates, and reservation statuses.
- STAFF: Maintains employee information and job positions.
- PAYMENT: Records payment transactions and methods.

Features
- Structured relational tables with appropriate primary and foreign key constraints.
- Custom queries and forms designed for data entry, searching, and status updates.

Technologies Used
- Microsoft Access
- Relational Database Design (RDBMS)
- SQL
